Server Control Panel

Edit your rates, fake-player behaviour, auto-play and more - no server, no login, no editing raw text files. Open your server's game folder to begin, and the config and data tabs both load from it.

Point it at your live server's game folder. Config changes are written straight back to the .ini files, and the Phantom Playstyles / Bot Clans tabs read game/data from the same pick, so there is no second folder to open. (You can still point it straight at game/config; the data tabs then open their own folder.)

Changes save to your .ini files. To apply them in-game, run //reload config - a few settings only take effect after a full server restart. (Editing here is the same as editing the .ini by hand)
